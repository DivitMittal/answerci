# Implementation Report

## Summary

AnswerCI has been implemented as a working Rust workspace for CLI-first, CI-native visibility regression testing for AI answer engines.

## Completed

- Workspace root `Cargo.toml` with crates for core domain types, providers, capture, extraction, scoring, reporting, GitHub scanning, and CLI.
- `answerci-core` serde domain types for prompt suites, prompts, entities, raw responses, observations, runs, mentions, citations, scores, and deltas.
- `answerci-providers` trait with manual JSONL import, mock provider for tests, and an informative OpenAI stub that performs no network calls.
- `answerci-capture` SQLite storage using bundled `rusqlite` for runs, raw responses, observations, and JSONL export.
- `answerci-extract` mention extraction, citation extraction, and placeholder unsupported-claim heuristics.
- `answerci-score` metrics and unit tests over fixture-style observations.
- `answerci-report` Markdown report generation.
- `answerci-github` offline local README/docs scanner for GitHub-style repositories.
- `answerci-cli` subcommands: `init`, `suite new`, `scan-github`, `run`, `diff`, `report`, and `ci --fail-on citation-regression`.
- JSON schemas for prompt suites, runs, and observations.
- Example prompt suite, manual-import fixture, and sample report generated by the CLI.
- Documentation for architecture, metrics, provider adapters, GitHub mode, CI mode, and ethics.
- GitHub Actions CI workflow and AnswerCI visibility workflow example.

## Stubbed or intentionally limited

- `OpenAiProvider` is a stub and returns an informative error instead of making live API calls.
- Unsupported-claim detection is a deterministic placeholder heuristic, not full fact verification.
- GitHub mode is offline and scans local README/docs only; it does not call GitHub APIs.
- CI mode currently supports `--fail-on citation-regression`; more policies are planned.
- Reports are Markdown-only in the MVP.

The sample report was generated for real with:

```bash
rm -rf .answerci
nix shell nixpkgs#cargo nixpkgs#rustfmt nixpkgs#clippy -c cargo run -p answerci-cli -- run \
  --suite examples/prompt-suites/oss-project.yaml \
  --providers manual:examples/manual-imports/sample-run.jsonl \
  --store .answerci/runs.db \
  --run-id sample
nix shell nixpkgs#cargo nixpkgs#rustfmt nixpkgs#clippy -c cargo run -p answerci-cli -- report \
  --suite examples/prompt-suites/oss-project.yaml \
  --store .answerci/runs.db \
  --run sample \
  --format markdown \
  --output examples/reports/sample-report.md
```
